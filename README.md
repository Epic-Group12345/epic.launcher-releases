# tugen.releases

Релизы лаунчера TUGEN и обновления по воздуху. Файлы публикует CI репозитория лаунчера, руками их не правят.

## Что скачать

Последний релиз — на странице [Releases](https://github.com/Epic-Group12345/tugen.releases/releases/latest).

| Файл | Система | Как поставить |
| --- | --- | --- |
| `tugen-setup-win-x64.exe` | Windows 10/11 x64 | Запустите установщик: он скачает лаунчер и создаст ярлыки |
| `tugen-portable-win-x64.zip` | Windows 10/11 x64 | Распакуйте в любую папку и запустите `epiclauncher.exe` |
| `tugen-macos-universal.dmg` | macOS 14 и новее, Apple Silicon и Intel | Откройте образ и перетащите TUGEN в «Программы» |

### macOS

Поддержка macOS пока идёт по остаточному принципу: основная платформа — Windows.

`tugen-macos-universal.dmg` появится в релизах, начиная с первого после того, как в лаунчер войдёт сборка
под macOS. В более ранних релизах его нет.

Сборка не подписана сертификатом Apple, поэтому при первом запуске macOS её не откроет. Чтобы разрешить
запуск, откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть»
рядом с сообщением о TUGEN. Это нужно сделать один раз.

## Обновления по воздуху

Релиз `ota` хранит `manifest.json` и бандлы JS. Лаунчер сам скачивает новый бандл, если тот собран под его
нативное ядро. Ядро приложения macOS отмечено в манифесте полем `platform: "macos"`.
